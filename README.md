# Для тебя — интерактивная открытка

Романтическая одностраничная открытка: закрытый конверт, восковая печать и письмо, которое открывается по мере прокрутки. Ниже письма — вторая глава: тихий утренний луг с зелёной палитрой, травой и посланием для Даши. Написана на чистом HTML, CSS и JavaScript — без библиотек, сборщиков и внешних изображений.

## Структура

```text
.
├── index.html       — разметка, SVG-иконки и текст письма
├── css/
│   └── style.css    — вся визуальная часть, конверт, бумага, частицы
├── js/
│   └── script.js    — сценарий прокрутки, частицы, интерактивность
└── README.md
```

## Как открыть

Просто откройте `index.html` в браузере. Все стили и скрипт подключаются локально.

Если нужен локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

## Где менять текст

1. **Послание в письме** — `index.html`, блок `.letter__body`. Там есть комментарий:

   ```html
   <!-- ✏️ ВСТАВЬТЕ СВОЙ ТЕКСТ ЗДЕСЬ. -->
   ```

   Можно менять абзацы, заголовок `Любимая,`, подпись и имя. Для красивого результата лучше оставить 3–5 коротких абзацев: открытка рассчитана на компактное письмо.

2. **Заголовок на первом экране** — `index.html`, блок `.intro`.

3. **Романтический финал предыдущей главы** — `index.html`, блок `.outro`.

4. **Послание для Даши в зелёной секции** — `index.html`, блок `.meadow__letter-variant` внутри `#meadow`. Внутри есть комментарий с тремя вариантами текста. Каждому абзацу нужен `data-meadow-reveal`, чтобы сохранилось каскадное появление.

5. Элементы с атрибутом `data-reveal` появляются по очереди. Если добавите новые абзацы, просто продублируйте этот атрибут — анимация подстроится под их количество.

## Настройка цветов

Все основные цвета и шрифты собраны в `:root` в начале `css/style.css`:

```css
--night: #160817;
--plum: #3f1737;
--rose: #e6a0ae;
--gold: #f0cf9d;
--paper: #fdf6e9;
--ink: #4d2a38;
```

- `--env-width` — размер конверта.
- `--env-ratio` — пропорции конверта.
- `--font-display`, `--font-serif`, `--font-sans` — шрифтовые стеки.
- Размер текста письма регулируется в `.letter__body` (свойство `font-size`).

## Настройка анимации

В `js/script.js` есть объект `TIMELINE`. Значения — это точки прогресса прокрутки от `0` до `1`:

```js
const TIMELINE = {
  seal:  [0.015, 0.145],
  flap:  [0.055, 0.325],
  rise:  [0.225, 0.600],
  focus: [0.500, 0.770],
  text:  [0.510, 0.900],
  hint:  [0.000, 0.085],
  intro: [0.000, 0.100]
};
```

Например, чтобы бумажка выезжала быстрее, сдвиньте `rise` влево или уменьшите второй параметр.

Длину всей scroll-сцены задаёт `.story` в `css/style.css` (`height: 340svh`). Чем больше значение, тем медленнее и плавнее раскрывается открытка.

## Что реализовано

- Анимация привязана к прокрутке и плавно откатывается назад.
- 3D-открытие клапана через `rotateX` и `perspective`.
- Выезд бумажки, мягкая доводка, покачивание и последовательное проявление строк.
- Наклонная восковая печать, пульсация и «отпускание» при открытии.
- Плавающие сердечки, звёздочки и лепестки, сгенерированные на JavaScript.
- Мягкие световые пятна, ореол, кольцо и зернистая текстура.
- Кнопка-подсказка «Листайте вниз», клик по конверту и кнопка «Прочитать ещё раз».
- Адаптивность: узкие телефоны, обычные смартфоны, альбомная ориентация, планшеты и десктоп.
- Поддержка `prefers-reduced-motion` и запасной вариант без JavaScript.
- Без горизонтальной прокрутки; анимации построены на `transform` и `opacity`.

## Секция «Утренний луг»

Новая глава находится после `.outro` и имеет `id="meadow"`.

- **Переход палитры.** Верхняя вуаль `.meadow::before` повторяет сливово-розовый градиент предыдущей секции и растворяется по маске в лесную зелень. Поэтому граница между блоками читается как рассветный горизонт, а не как резкий стык.
- **Трава.** Три SVG-слоя (`.meadow__grass-layer--far`, `--mid`, `--near`) лежат на разной глубине. Параллакс двигает их с разной скоростью по `data-grass-depth`, а внутренние обёртки `.meadow__grass-sway` покачиваются CSS-анимациями с разными амплитудами и задержками.
- **Reveal.** `IntersectionObserver` добавляет секции `.is-revealed`; у каждого элемента с `data-meadow-reveal` есть переменная `--reveal-delay`, которую JavaScript заполняет каскадом. Заголовок, строки письма и подпись появляются друг за другом.
- **Дыхание.** `.meadow__breath`, туман и светлячки включаются только при `.is-in-view` и используют только `transform` и `opacity`.
- **Тексты.** В HTML-комментарии рядом с активным письмом лежат три варианта: короткий, средний и развёрнутый. Скопируйте выбранный в `.meadow__letter-variant` и сохраните атрибуты `data-meadow-reveal`.
- **Настройка параллакса.** Атрибут `data-grass-depth="1"` у переднего слоя означает максимальное смещение. Уменьшите число, чтобы слой двигался спокойнее.

### Три варианта послания

**Короткий**

> Даша,
>
> я люблю не громкие слова, а вот это:
> когда ты рядом, мир становится тише — и мне хорошо.

**Средний**

> Даша,
>
> есть утро, которое пахнет травой и дождём, — и есть ты: моё самое тихое «наконец-то».
> Я не обещаю идеальных дней. Я обещаю возвращаться к тебе, даже когда мир шумит слишком громко.
> И каждый раз выбирать твой смех, твою руку, наше обычное «рядом».
> Я люблю тебя. Просто. Честно. Каждый день.

**Развёрнутый**

> Даша,
>
> я думал, что нежность — это про большие слова. Она оказалась про другое: про твой смех в соседней комнате, про чай, который остывает, пока мы говорим, про руку, которую хочется держать чуть дольше обычного.
> С тобой я не спешу казаться кем-то другим.
> И если однажды собьюсь с пути, пусть моим компасом остаётся твой голос.
> Я люблю тебя — тихо, честно, каждый день.

## Советы

- Не вставляйте слишком длинное письмо: сцена рассчитана на один экран. Для длинного текста можно увеличить `.story` и доработать финальную фазу.
- Если хочется использовать каллиграфический шрифт с поддержкой кириллицы, подключите его локально через `@font-face` и добавьте в `--font-display` / `--font-serif`.
- Для публикации достаточно загрузить папку на любой статический хостинг (GitHub Pages, Netlify, Vercel и т. п.).
